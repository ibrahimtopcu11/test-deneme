# 💖 Prensesim için

Sena Nur için hazırlanmış, animasyonlu küçük bir barışma sitesi.

## GitHub Pages'e yükleme

1. GitHub'da yeni bir repo aç (ör. `sena-icin`), **Public** olsun.
2. Bu klasördeki dosyaları (`index.html`, `style.css`, `script.js`, `README.md`) repoya yükle
   (“Add file → Upload files” ile sürükleyip bırakman yeterli).
3. Repo içinde **Settings → Pages** bölümüne gir.
4. **Source:** `Deploy from a branch`, **Branch:** `main` ve `/ (root)` seç, **Save**'e bas.
5. 1–2 dakika sonra link hazır: `https://KULLANICI-ADIN.github.io/sena-icin/`

## Yazıları değiştirmek

Tüm isimler ve mektup cümleleri `script.js` dosyasının en üstündeki `CONFIG` kısmında.
